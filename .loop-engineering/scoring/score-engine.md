# Score Engine
Toplam = Σ(kategori ağırlığı × kanıt faktörü). Evidence-bound kategoriler
(goal_alignment, functional_correctness, verification_strength, reliability)
doğrudan verification pass rate ile ölçeklenir. Verifier reddi = quality_threshold tavanı.
Net Improvement = New Verified Score - Baseline - Regression - Risk - Cost cezaları.
Net improvement < minimum_improvement ise değişiklik otomatik kabul edilmez.
